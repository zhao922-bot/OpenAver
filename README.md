# OpenAver 中文增强版

这是基于 [slive777/OpenAver](https://github.com/slive777/OpenAver) 制作的个人中文增强分支，重点改善本地影片整理、中文元数据、批量维护、下载任务和故障恢复体验。

> 当前改版分支：`openaver-cn-local`<br>
> 当前版本：`0.10.11+openaver-cn-local-20260715-ops10`

## 分支说明

- `main`：保留并跟随原作者的新版本历史，目前已进入 0.12.x 系列。
- `openaver-cn-local`：当前实际使用和持续维护的中文增强版，基于受保护的 0.10.11 本地构建。

两个分支的开发历史差异较大。本分支没有强行覆盖 `main`，也不表示已完整合并原作者 0.12.x 的全部功能。

## 主要增强

### 中文元数据

- 支持搜索结果与本地浏览界面的 AI 标题翻译。
- 女优姓名使用可维护的日文原名、常用中文名及别名数据库，不依赖逐字机翻。
- 翻译标题时保护女优姓名，避免同一姓名出现漏译、误译或多种译名。
- 支持翻译确认、字段来源记录、字段锁定和翻译回退。

### 自动整理与重命名

- 根据番号识别元数据，自动补充日文标题和女优姓名。
- 支持单个及批量重命名预览、应用和回滚。
- 同步更新视频、NFO、封面、剧照路径和数据库记录。
- 使用原子重命名日志与崩溃恢复机制，降低文件和数据库不一致风险。

### NFO 与剧照维护

- NFO 更新以磁盘文件为事实来源，避免反复搜索已经完整的视频。
- 支持只更新选中的缺失项、无变化指纹跳过和失败后安全重试。
- 一键检查并批量补齐缺少的本地剧照。
- 单视频和批量剧照接口均校验扫描目录、数据库记录和权威番号。
- 图片使用原子写入并检查 JPEG、PNG、WebP 等文件签名，避免损坏残片被当作有效剧照。

### 授权媒体下载

- 接受用户有权保存的 MP4 或 m3u8 媒体直链。
- 使用 yt-dlp 与 FFmpeg 下载、合并并封装为 MP4。
- 可设置同时下载数量和 HLS 分片线程数。
- 显示进度、速度和真实剩余时间，支持暂停、继续、取消及失败后更换直链重试。
- 下载后自动建立独立文件夹、生成 NFO/封面并导入本地媒体库。
- NFO 或封面失败不会误报为下载失败，而会标记为“已下载；入库需检查”。

下载功能仅用于用户本人拥有、已获授权或法律允许保存的媒体。项目不提供站点绕过、DRM 破解或未经授权的资源获取功能。

### 运维与安全

- 增加运维仪表板、元数据完整度检查、重复项检查和可修复问题列表。
- 诊断包会清理 Bearer Token、查询参数和媒体签名地址。
- 支持增量扫描、缩略图缓存、扫描目录白名单和局域网访问保护。
- 当前自动化测试共 174 项，覆盖重命名恢复、NFO 更新、剧照批处理、下载错误和安全边界。

## 使用方式

本分支保存的是改版源码和测试，不包含 `.gitignore` 排除的内置 Python、FFmpeg、yt-dlp、用户配置及运行数据。建议在已安装的 OpenAver 0.10.11 Windows 版本上使用对应源码构建，或由发布包提供完整运行环境。

开发与验收使用项目自带运行时：

```powershell
.\python\python.exe tests\run_all.py
```

本地服务默认地址：

```text
http://127.0.0.1:49152
```
